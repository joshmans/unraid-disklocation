**Disk Location**

Locate your drives and assign them to a graphical tray map to get full overview of installed hard drives in your system.

---

**Manufacturer logos:** the tray map can optionally show a manufacturer logo per drive, alongside a generic HDD/SSD/NVMe type icon. Disk Location does not ship any manufacturer logos itself - see [`disklocation/pages/styles/manufacturers/README.md`](disklocation/pages/styles/manufacturers/README.md) for how to add your own.
